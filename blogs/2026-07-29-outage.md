Jul 29 , 19:57 UTC Resolved - hex.pm and the API have been stable since 19:11 UTC, and package file preview pages have been serving normally since 19:36 UTC. The cause was a sustained flood of automated traffic against package file preview pages. Because each of those requests unpacks a package archive, the volume exhausted memory on the web servers and took them out of rotation, which is why the site returned errors.
